# Frontend rules

Shared FE governors. Skills under `.cursor/skills/frontend/` declare which of these they follow.

| Path | Concern |
|------|---------|
| [`code/`](code/) | Write/place FE code (`ui`, `page-shell`, `modules`, `surfaces`) |
| [`auth.mdc`](auth.mdc) | Identity / membership |
| [`mutations.mdc`](mutations.mdc) | Server actions / debit / cascade |
| [`business/`](business/) | Product domains (lead-gen, tenants) |
