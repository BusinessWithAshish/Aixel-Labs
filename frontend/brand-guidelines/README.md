# Brand guidelines pack

Paste-ready brand kit for **any** AI agent (Cursor, ChatGPT, Claude, CLI, etc.).

## Quick start

1. Open [`BRAND.md`](BRAND.md) — that file is the full brief.
2. Attach or `@`-mention the logos in [`assets/`](assets/):
   - `aixellabs-logo.png` — icon / mark (“A.”)
   - `aixellabs-full-logo.png` — full “Aixel Labs” lockup
   - `aixellabs-logo.svg` — vector mark
3. Prompt example:

> Use the attached Aixel Labs brand brief and logos. Design [X] following the colors, logo rules, and product context exactly. Brand name is Aixel (not Pixel).

## Contents

| Path | Purpose |
|------|---------|
| [`BRAND.md`](BRAND.md) | **Copy-paste brief** — product, logo, colors, type, UI rules |
